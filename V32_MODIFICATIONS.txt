V32 — TVA intégrée sur créations factures/retours

Modifications principales :
- Module Chantier : maintien TVA sur factures clients, factures achats et retours.
- Module Magasinier : ajout du choix de TVA lors de la création d'une facture fournisseur.
- Module Magasinier : ajout du choix de TVA lors de la création d'un retour marchandise.
- Enregistrement complet en base : amount HT, taux TVA, montant TVA, montant TTC.
- Aperçu immédiat HT / TVA / TTC dans les formulaires Magasinier.
- Gestion : calculs de rentabilité repris sur les montants HT, avec TVA collectée et TVA déductible nette affichées.
- Rapport Gestion : tableaux factures/retours enrichis avec HT / TVA / TTC.

Base de données :
- Pas de nouvelle migration obligatoire si schema-complet-v31.sql a déjà été exécuté.
- Les colonnes TVA utilisées sont : amount_ht, tva_rate, amount_tva, amount_ttc.
