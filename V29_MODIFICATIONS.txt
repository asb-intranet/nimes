V29 - Modifications ASB Intranet

Terrassements :
- Ajout du planning terrassement dans le menu général Terrassement.
- Ajout d'un champ facturation client prévue sur la fiche terrassement.
- Ajout des factures terrassement après création du chantier terrassement.
- Ajout d'un rapport PDF terrassement : facturation client, factures, locations d'engins, solde/marge estimée.
- Modification du planning terrassement directement dans la fiche, sans popup navigateur.
- Matériel terrassement : ajout, modification, suppression, pièce jointe photo/document.
- Points de vigilance terrassement : ajout, modification, suppression, pièce jointe photo/document.

Magasinier / Gestion :
- Les retours marchandise sont déduits des dépenses chantier dans la partie Gestion.
- Les retours apparaissent dans le rapport PDF de gestion chantier.

Affectations :
- Les affectations de salariés sont allégées : les chantiers archivés ne sont plus affichés dans la sélection et dans les affectations visibles.
- Les données d'affectation restent en base pour historique, mais elles ne polluent plus l'affichage courant.
